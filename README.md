# Nakil Rehberi

Türk Nefroloji Derneği **Transplantasyon Nefrolojisi Pratik Uygulama Önerileri** (Genişletilmiş 2. Basım, 2026; Ed. Prof. Dr. Aydın Türkmen) temelli erişkin böbrek nakli rehberi.

- 29 konu: mevzuat, alıcı ve canlı verici değerlendirmesi, immünoloji ve desensitizasyon, erken dönem sıvı ve immünsüpresyon, komplikasyonlar, TCMR, ABMR, Banff, enfeksiyonlar, KV, metabolik, kemik, hematoloji, malignite, gebelik, genetik hastalıklar, greft yetmezliği, poliklinik izlemi, beslenme, biyobelirteçler
- 23 klinik hesaplayıcı (takrolimus, ATG, valgansiklovir, Banff indeksleri, desensitizasyon riski, BK, aşı uygunluğu, izlem takvimi vb.)
- Çevrimdışı çalışan PWA: ana ekrana eklenebilir

Uygulama: https://karadr79.github.io/NakilRehberi/

Klinik karar desteği amaçlıdır; hasta özelinde klinik değerlendirmenin yerini tutmaz.

RTEÜ Tıp Fakültesi Nefroloji Bilim Dalı · Prof. Dr. Ekrem Kara
